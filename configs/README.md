# Evaluation configurations

[pilot.yaml](pilot.yaml) contains shared model settings, task budgets, execution environment and task selection.

The pilot covers 100 Baseline tasks, 100 Fingerprint tasks and five Frontier cases. Paths in `pilot.yaml` are relative to the repository root. Task materials and input availability are described in [benchmarks/README.md](../benchmarks/README.md).

Host hardware records the evaluation machine; per-task resource limits are listed separately.
